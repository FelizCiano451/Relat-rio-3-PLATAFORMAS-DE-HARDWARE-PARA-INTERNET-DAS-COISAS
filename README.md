Utilizando novamente o sensor de ultrassom HC-SR04, foi feito um programa para determinar a distância de um objeto colocado a frente desse sensor.

Dessa vez utilizando interrupção para cronometrar o tempo de forma mais precisa entre a subida do nível de sinal do pino ECHO e a sua descida.

Da mesma forma que na atividade anterior, o programa informa a distância através de sua porta serial textualmente.

A interrupção foi realizada através de um código em estilo Arduino.
